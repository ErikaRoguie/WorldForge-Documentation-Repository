# WorldForge Documentation Repository

> **Excelsior. We Live.**

WorldForge is a **digital civilization** where life, learning, stories, collections, skills, history, creativity, and communities connect inside one persistent world.

This repository contains the founding constitution, product vision, world architecture, education model, governance principles, development roadmap, and a working front-end prototype.

## Founder’s Promise

> **Build a Home. Join a Community. Explore Every World. Leave Every Place Better Than You Found It.**

## Repository Map

- `constitution/` — permanent “Print in Steel” principles
- `vision/` — mission, manifesto, and design philosophy
- `architecture/` — world and product-system architecture
- `academy/` — educational institutions and all-skills model
- `simulation/` — clearly separated “What If?” laboratories
- `community/` — families, neighborhoods, and guilds
- `governance/` — Explorer rights, safety, and amendment rules
- `roadmap/` — phased development plan
- `docs/` — glossary and standards
- `prototype/` — working static Explorer Home prototype

## Run the Prototype

Open `prototype/index.html` in a browser, or run:

```bash
cd prototype
python -m http.server 8000
```

Then visit `http://localhost:8000`.
