# Print in Steel Standard

1. Every Explorer has dignity.
2. Every Explorer has a Home.
3. Every Explorer belongs.
4. No Explorer journeys alone.
5. Every skill matters.
6. Every honest profession has dignity.
7. History is preserved.
8. Reality and simulation remain clearly separated.
9. Learning is lifelong.
10. Communities matter.
11. Creativity is celebrated responsibly.
12. Explorer time, privacy, collections, and achievements deserve protection.
13. WorldForge should leave people and places better than it found them.

Interfaces and technologies may evolve. These commitments must not quietly change.
