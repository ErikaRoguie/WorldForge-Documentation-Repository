# World Structure

```text
WorldForge
├── Explorer Home
├── Neighborhood
├── Guild Network
├── WorldForge Academy
├── Hall of History
├── Marketplace District
├── Simulation Institute
├── Explorer Archives
└── World Community
```

The Explorer Home is the personal center. The Neighborhood is the social center. The Academy is the learning center. The Hall of History is the factual memory center. The Simulation Institute is the clearly marked experimental center.
